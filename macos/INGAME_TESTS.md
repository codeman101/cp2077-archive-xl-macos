# In-game tests for ArchiveXL (end checklist)

One line per feature that only fires in game. Each line says what to do and which log line proves it. Run the game through
`launch_phase6.sh` (since Gate A1 the source-built ArchiveXL is the default: the launcher installs it for that session only, puts the old NightCity
Console ArchiveXL back in its cleanup, and runs with `CODEWARE_MAC_DIAG=1`; `--no-archivexl-source` goes back to a session without ArchiveXL). Add `--with-equipmentex-archive` to switch `EquipmentEx.archive` on for the
session. The launcher prints `Logs (send these): /tmp/cp2077-phase6-<stamp>-*`; every `[axl]` line below is in the `-launch.log` file.

"Seen at the menu" means seen in a menu boot of the build named; the rest has not run yet. "Crash-free" means no `[crash]` line.

checklist below, quit the game normally, and send the printed `Logs (send these): /tmp/cp2077-phase6-<stamp>-*` files. Menu part (already checked by
